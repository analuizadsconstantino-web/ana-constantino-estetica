# Ana Constantino Estética Integrativa — site institucional

Site estático responsivo (HTML, CSS e JavaScript), preparado para publicação no Render Static Site.

## Publicação no Render
1. Envie os arquivos `index.html`, `style.css` e `script.js` para um repositório GitHub novo.
2. No Render, crie um **Static Site** e conecte esse repositório.
3. Build Command: deixe vazio (ou `echo "Static site"` se o formulário exigir).
4. Publish Directory: `.` (raiz do repositório).
5. Faça o deploy.

## Antes de publicar
- Em `script.js`, preencha `WHATSAPP_NUMBER` com o número profissional completo, apenas dígitos, incluindo 55 e DDD.
- Confirme o Instagram e a cidade/bairro.
- Confirme os valores de cada procedimento no `index.html`.
- Substitua imagens ilustrativas por fotografias próprias, quando disponíveis.
- A seção de resultados atualmente usa imagens ilustrativas e informa isso; substitua por fotos reais autorizadas antes de divulgar resultados de pacientes.
- Inclua endereço, horários e outras informações apenas após confirmação.

## Observações
- O site adapta o layout para computadores, tablets e celulares.
- O Home Care é apenas uma explicação pública do serviço, sem login, dados ou cadastro de pacientes.
- Não inclui painel administrativo ou armazenamento de dados.
